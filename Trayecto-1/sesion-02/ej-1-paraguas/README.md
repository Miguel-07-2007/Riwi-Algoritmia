# El paraguas

Que Johan llegue con paraguas no permite asegurar que llovió. La regla dice que si llueve lleva paraguas, pero también podría llevarlo para protegerse del sol.

| Llueve | Lleva paraguas | ¿Cumple la regla? |
| --- | --- | --- |
| Sí | Sí | Sí |
| Sí | No | No |
| No | Sí | Sí |
| No | No | Sí |

Con paraguas son posibles tanto la primera como la tercera fila. No se puede deducir cuál ocurrió.
